  <action>
Create `supabase/functions/signage-check/index.ts` with the decoupled handler:
```ts
export async function handleSignageCheck(
  checkId: string,
  deps: { svc: Svc; vision: (img: { content?: string; imageUri?: string }) => Promise<{ text: string[] }>; apiKeyPresent: boolean },
): Promise<{ confirmed: boolean | null }>
```
Logic:
1. If `!deps.apiKeyPresent`: write `clips.signage_confirmed = null`, log_event('check.signage_skipped', context {reason:'no_api_key'}), return `{ confirmed: null }`. NEVER throw.
2. Read the latest clip's mux_playback_id + the check's venue name (join venues via checks.venue_id; fallback to checks.location_label).
3. Build the image reference. Because playback policy is 'signed' (Pitfall 2): fetch the thumbnail bytes server-side using the Mux signing key and pass as base64 `content`, OR mint a short-lived image JWT for `imageUri`. Prefer base64 content (avoids Vision's externally-hosted-image caution). Pass to `deps.vision`.
4. Fuzzy-match: lowercase + strip punctuation; `confirmed = detectedText.some(t => t.includes(venueNameNormalized) || venueNameNormalized.includes(t))`. If no text at all -> confirmed=false (read but no match) ... but if Vision errored / empty response treat as null (couldn't run). Use market_config.signage_min_conf only if you incorporate Vision confidence scores; otherwise document the simple contains-match as the v1 strategy (tunable later).
5. `from('clips').update({ signage_confirmed: confirmed }).eq('check_id', checkId)`.
6. log_event('check.signage_checked', context { confirmed, detected_sample: detectedText.slice(0,3) }).
7. Return `{ confirmed }`.
8. CRITICAL: never call transition_check or reset_check_for_redispatch (D-06). Wrap the whole body in try/catch that, on any error, writes signage_confirmed=null + logs and returns { confirmed: null } — a signage failure must NEVER affect delivery.

Live entrypoint: `import.meta.main` + `Deno.serve` reading `{ checkId }`, building the real `vision` dep that does the REST fetch to `https://vision.googleapis.com/v1/images:annotate?key=${Deno.env.get('GOOGLE_VISION_API_KEY')}` (Pattern 5, REST not NPM — Pitfall 7), with `apiKeyPresent: !!Deno.env.get('GOOGLE_VISION_API_KEY')`.
