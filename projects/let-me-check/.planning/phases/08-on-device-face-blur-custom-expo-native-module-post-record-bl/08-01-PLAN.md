The native module surface (from 06-RESEARCH-BLUR-V2 Part 3), to be created in this step:

```ts
// modules/lmc-blur/src/LmcBlur.types.ts
export type BlurMode = 'gaussian' | 'pixelate';

export type BlurStatus = 'blurred' | 'no_faces' | 'failed';

export type BlurResult = {
  outputPath: string;     // file:// path to the output clip
  facesBlurred: number;   // count of faces blurred (telemetry)
  status: BlurStatus;     // 'blurred' = faces blurred; 'no_faces' = none found, original returned (safe to deliver); 'failed' = caller must use the fallback, NEVER deliver as if blurred
};

export type BlurOptions = { radius?: number; mode?: BlurMode };
```

```ts
// JS-facing call (modules/lmc-blur/index.ts re-exports this)
export function blurFaces(inputPath: string, opts?: BlurOptions): Promise<BlurResult>;
```

Expo Modules API is New-Arch-native and auto back-compatible (docs.expo.dev/modules/overview). The packaging path is: local module under `modules/lmc-blur/` created with `npx create-expo-module --local lmc-blur`, auto-linked by prebuild — NO manual ios/ Podfile/Xcode edits (ios/ is gitignored, D-03).
