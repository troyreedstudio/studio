<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI deploy → live project | Secrets set via `supabase secrets set`, never committed |
| Stripe webhook endpoint → Edge | Signing secret must match for any event to be trusted |
| Mux webhook → stripe-capture | Service-role trigger; capture is never client-initiated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-22 | Information Disclosure | secrets in repo | mitigate | Secrets set via CLI secrets only; .env gitignored (git check-ignore gate); no secret in any committed file |
| T-04-23 | Spoofing | unregistered/forged webhook | mitigate | STRIPE_WEBHOOK_SECRET from the registered endpoint; test-event 200 + forged-event 401 confirms verify is live |
| T-04-24 | Tampering | live vs test money | accept | TEST mode only this phase; live keys + US entity are a launch gate (see deferred note) — no real money can move |
| T-04-25 | Repudiation | deploy actions | mitigate | Migration + function changes committed to git; event_log captures runtime events once live |
</threat_model>
